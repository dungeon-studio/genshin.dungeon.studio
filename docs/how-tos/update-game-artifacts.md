# How to regenerate the Genshin Impact artifact set roster

`packages/game-data/src/artifacts.generated.ts` is generated by
`@genshin/game-data-codegen`. Edit the generator, not the file.

The roster covers sets with 5-star pieces; lower-rarity sets are left out.

## Regenerate the roster

Optionally pull newer game data first:

```bash
pnpm --filter @genshin/game-data-codegen up genshin-db
```

Build the generator and run it:

```bash
pnpm turbo run build --filter @genshin/game-data-codegen
pnpm --filter @genshin/game-data-codegen generate artifacts
```

Confirm the gates pass:

```bash
pnpm turbo run typecheck test lint --filter @genshin/game-data
```

## Resolve a set the generator rejects

`generate artifacts` aborts when a 5-star set arrives without both a 2-piece
and a 4-piece bonus. Only the single-piece circlet sets lack them, and those
cap at 4 stars, so an abort means `genshin-db` changed shape: inspect the named
record before widening the check in
`tools/game-data-codegen/src/artifacts.ts`.
