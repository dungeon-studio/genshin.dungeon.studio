# How to regenerate the Genshin Impact elemental resonances

`packages/game-data/src/resonances.generated.ts` is generated by
`@genshin/game-data-codegen`. Edit the generator, not the file.

Regeneration fetches from
[AnimeGameData](https://github.com/DimbreathBot/AnimeGameData) at a pinned
commit, so it needs network access and `generate all` skips it. The pin is the
commit named in the generated module's header.

The daily workflow's `Refresh game data` job picks up new commits. Regenerate by
hand after changing the generator.

## Regenerate the resonances

Build the generator and run it:

```bash
pnpm turbo run build --filter @genshin/game-data-codegen
pnpm --filter @genshin/game-data-codegen generate resonances
```

To read a newer commit, pass it with `--commit`. The module, and so the pin,
changes only when the resonances at that commit differ from the shipped ones.

Confirm the gates pass:

```bash
pnpm turbo run typecheck test lint --filter @genshin/game-data
```

## Resolve a resonance the generator rejects

An abort that names a resonance means the game changed a rule the
`ResonanceCondition` union encodes, such as adding an element or a
three-of-a-kind trigger. Inspect that record, then widen the union in
`packages/game-data/src/resonances.ts` and the element mapping in
`tools/game-data-codegen/src/resonances.ts`.
