# How to regenerate the Genshin Impact elemental resonances

`packages/game-data/src/resonances.generated.ts` is generated by
`@genshin/game-data-codegen`. Edit the generator, not the file.

`genshin-db` carries no resonance data, so this generator reads the game's own
tables, as extracted from the game client by
[AnimeGameData](https://github.com/DimbreathBot/AnimeGameData). It fetches them over the network at the commit pinned in
`ANIME_GAME_DATA` in `tools/game-data-codegen/src/resonances.ts`. The generated
file's header records that commit and the upstream paths.

## Regenerate the resonances

To pick up a balance change, first set `ANIME_GAME_DATA.commit` to a newer
AnimeGameData commit. A regeneration at the same commit rewrites the same
file.

Build the generator and run it:

```bash
pnpm turbo run build --filter @genshin/game-data-codegen
pnpm --filter @genshin/game-data-codegen generate resonances
```

Confirm the gates pass:

```bash
pnpm turbo run typecheck test lint --filter @genshin/game-data
```

## Resolve a resonance the generator rejects

`generate resonances` aborts unless upstream lists one pair resonance per
element and one all-different resonance, each with English text. An abort
means the game changed a rule the `ResonanceCondition` union encodes, such as
a new element or a three-of-a-kind trigger. Inspect the record the error names
before widening the union in `packages/game-data/src/resonances.ts` and the
mapping in `tools/game-data-codegen/src/resonances.ts`.
